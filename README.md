# Job Tracker

A web app I'm building during my own job search to keep track of applications,
their status and follow-ups.

**Status:** 🚧 In progress. The frontend is being built first; a .NET backend will follow.

## Tech stack

- **Frontend:** React 19, TypeScript, React Router, Bootstrap
- **Mock API (for now):** json-server
- **Planned backend:** ASP.NET Core Web API, EF Core, SQL Server

## Features

- [ ] Dashboard
- [ ] Add a new application
- [ ] List, search, sort and delete applications
- [ ] Simple report (counts by status)
- [ ] Login with JWT (planned with the backend)

## Run locally

    cd frontend
    npm install
    npm run dev
